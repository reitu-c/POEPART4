# Cybersecurity Awareness Chatbot

## Project Description
The Cybersecurity Awareness Chatbot is a C# Windows Forms application designed to help users learn about cybersecurity topics. It provides users with information about online safety, common cyber threats, and security best practices through an interactive chatbot interface.

## Features
- User-friendly graphical user interface (GUI)
- Cybersecurity-related chatbot responses
- Task management functionality
- Reminder system
- Stores and manages user tasks
- Provides cybersecurity awareness information
- Input validation and error handling

## Technologies Used
- C#
- .NET Windows Forms
- Visual Studio 2022
- MySQL Database (if you used it)

## How to Run the Project
1. Download or clone the repository
2. Open the project in Visual Studio 2022
3. Restore required packages (if needed)
4. Build the solution
5. Run the application

## Project Structure
- Models: Contains data classes used by the application
- Forms: Contains the graphical user interface
- Data: Handles database/data storage operations
